Detailed Description

these tables are used in FAT16+32 volumes to determine the BPB.sectors_per_cluster value from the BPB.total_sectors value

assumes that the BPB.bytes_per_sector is 512

since FAT12 is only used for floppy disks, the values are constant and a table is not needed. what exactly these values are is fucking unkown to me, microsoft mentions them and never provides them...
