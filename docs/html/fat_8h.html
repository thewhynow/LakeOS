Detailed Description

fat12/16/32 driver, a vfs driver (see FAT_init). on-disk structures are only visible inside the driver (FAT_H_INTERNAL), everything else gets opaque pointers and the FAT* api at the bottom

enum e_DirEntryAttributes

the attributes of a directory entry, or'd together upper two bits of attrib byte are reserved and should be set to 0

Enumerator
ENTRY_ATTR_READ_ONLY 

writes to the file should fail

ENTRY_ATTR_HIDDEN 

file should not show up in normal directory listings

ENTRY_ATTR_SYSTEM 

file is part of the operating system

ENTRY_ATTR_VOLUME_ID 
  • there should only be one "file" that has this attribute
  • name of said file is the volume label
  • has to be in the root directory
  • first_cluster_* should be 0
ENTRY_ATTR_DIRECTORY 

file is a container for other files (no shit)

ENTRY_ATTR_ARCHIVE 

bit is set when the file is written, renamed, or created

ENTRY_ATTR_LONG_NAME 

all four set, marks a long name entry

ENTRY_ATTR_MASK_LONG_NAME 

what to mask the attributes with to check for ENTRY_ATTR_LONG_NAME
