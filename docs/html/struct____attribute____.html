Detailed Description

the first part of the boot sector (the bpb), the same on FAT12/16/32 at this point, the boot structure differs between FAT16+12 and FAT32

common Boot Sector extension between FAT16+12+32 but at different offsets

the rest of the FAT32 boot sector all fields defined here do NOT exist for FAT12+16 volumes

the fsinfo sector of a FAT32 volume

a directory entry (8.3 name), 32 bytes

a directory entry holding a piece of a long name, 32 bytes

one descriptor of the GDT

what lgdt wants

one gate of the IDT

what lidt wants

the saved state of whatever was running when an interrupt came in, handlers get a pointer to this. members are in reverse order they are pushed, so don't shuffle it also doubles as the context of a process (see t_Process)

one region of the memory map entries are size + 4 bytes apart, size doesn't count itself

the info struct grub passes in ebx like 3/4 of this is not relevant to me but i keep it anyway

◆ name

uint8_t __attribute__::name[11]

short name

  • if name[0] == 0xE5 then the directory entry is free; no file or directory is in this entry
  • if name[0] == 0x00 then the directory entry is free, AND all the other entries in the directory are also free
  • if name[0] == 0x05 then the actual byte value for name[0] is 0xE5; Japanese character sets use this value for a specific character
  • is broken into two parts: 8-character file name 3-character extension (implied '.' between name and extension)
    • lower-case characters are illegal
    • characters less than 0x20 (besides 0x05 special case) are illegal
    • 0x22, 0x2A, 0x2B, 0x2C, 0x2E, 0x2F, 0x3A, 0x3B, 0x3C, 0x3D, 0x3E, 0x3F, 0x5B, 0x5C, 0x5D, and 0x7C are illegal
    • name[0] != 0x20 (int)' '
