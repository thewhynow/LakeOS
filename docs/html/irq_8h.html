◆ PIC_REMAP_OFFSET

#define PIC_REMAP_OFFSET   0x20

vector the PIC maps IRQ0 to, so IRQ n lands on PIC_REMAP_OFFSET + n. 0x20 keeps them out of the way of the cpu exceptions (0 - 31)
